📌 Creating and Managing Threads

[!info] Navigation Module: [[09 - Multithreading and Concurrency/index|← Multithreading and Concurrency Overview]] Prev: [[09 - Multithreading and Concurrency/basics|← Basics]] Next: [[09 - Multithreading and Concurrency/thread-safety-and-synchronization|Thread Safety & Sync →]]

🎯 The Sequential Problem

Imagine placing an order requiring 3 sequential tasks:

  1. Send SMS (2s delay)
  2. Send Email (3s delay)
  3. Calculate ETA (5s delay)

Running this sequentially takes 10 seconds. With multithreading, it takes 5 seconds.

🛠️ Creating Threads in C++ (std::thread)

C++11 introduced <thread>. You can pass any callable (Functor, Free Function, Lambda) to a std::thread constructor, and it starts executing immediately.

1. Using Functors (Callable Objects)

cpp
#include <iostream>
#include <thread>
using namespace std;

struct SMSTask {
    void operator()() const {
        this_thread::sleep_for(chrono::seconds(2));
        cout << "SMS Sent.\n";
    }
};

int main() {
    thread t1(SMSTask{}); // Starts immediately
    t1.join();            // Blocks main thread until t1 finishes
    return 0;
}

2. Using Free Functions and Arguments

cpp
void sendNotification(string type, int delay) {
    this_thread::sleep_for(chrono::seconds(delay));
    cout << type << " Sent.\n";
}

int main() {
    thread t1(sendNotification, "SMS", 2); // Pass arguments directly!
    t1.join();
}

3. Using Lambdas

cpp
int main() {
    thread t1([]() {
        cout << "Lambda task running.\n";
    });
    t1.join();
}

[!warning] join() vs detach()

  • join(): Main thread waits for the thread to finish.
  • detach(): Thread runs completely independently in the background (Daemon thread). Once detached, it cannot be joined.

🚀 Retrieving Results (std::future & std::async)

A major demerit of std::thread with a void function is you cannot easily return a value. To get a return value, C++ provides std::future, std::packaged_task, and std::async.

The std::async Approach (Recommended)

std::async is a high-level API that automatically spawns a thread and returns a std::future object.

cpp
#include <iostream>
#include <future>
using namespace std;

string calculateETA() {
    this_thread::sleep_for(chrono::seconds(5));
    return "ETA: 25 minutes";
}

int main() {
    // Launch asynchronously. Returns a future representing the result.
    future<string> etaResult = async(launch::async, calculateETA);

    cout << "Doing other work while ETA is calculating...\n";

    // .get() blocks the main thread UNTIL the result is ready
    string result = etaResult.get(); 
    cout << result << "\n";
    return 0;
}

[!tip] std::launch::async vs std::launch::deferred

  • launch::async: Forces execution on a NEW thread.
  • launch::deferred: Lazy execution. The task executes on the calling thread only when .get() is called.

📊 Thread Lifecycle

    [*] --> Runnable : Create std::thread
    Runnable --> Running : OS Scheduler assigns CPU
    Running --> Blocked : Mutex lock, I/O, sleep

    Running --> Joinable : Function returns
    Joinable --> Terminated : thread.join() or detach()
