📖 What is Composition?

Composition is a strong form of aggregation where the child cannot exist independently of the parent. When the parent dies, the child dies too.

[!example] Real-World Analogy 🏠 A House has Rooms. If you demolish the house, the rooms cease to exist. A room can't exist without its house.

🧪 Code Example

cpp
class Room {
    string type;
    int area;
public:
    Room(string t, int a) : type(t), area(a) {}
    string getType() { return type; }
};

class House {
    vector<unique_ptr<Room>> rooms;  // Composition — House OWNS rooms
public:
    void addRoom(string type, int area) {
        rooms.push_back(make_unique<Room>(type, area));
    }

    ~House() {
        // Rooms are automatically destroyed with the house
        // unique_ptr handles cleanup
    }
};

int main() {
    House house;
    house.addRoom("Bedroom", 200);
    house.addRoom("Kitchen", 150);
    // When house goes out of scope, all rooms are destroyed too
}

[!quote] Key Takeaway Composition = "has a and owns it." The child lives and dies with the parent. Use unique_ptr in C++ to express this relationship clearly.
