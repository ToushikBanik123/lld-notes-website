📖 What is Dependency?

Dependency is the weakest relationship between classes. A class uses another class temporarily — typically as a method parameter, local variable, or return type.

[!example] Real-World Analogy 🖨️ A person uses a printer to print. They don't own the printer. They interact with it briefly and move on.

[!tip] UML Notation Dependency uses a dashed arrow (- - →) pointing to the class being depended on.

🧪 Code Example

cpp
class EmailService {
public:
    void sendEmail(string to, string message) {
        cout << "Email sent to " << to << ": " << message << endl;
    }
};

class OrderService {
public:
    // Dependency — uses EmailService temporarily
    void placeOrder(string item, EmailService& emailService) {
        cout << "Order placed: " << item << endl;
        emailService.sendEmail("customer@email.com", "Your order for " + item + " is confirmed!");
    }
};
