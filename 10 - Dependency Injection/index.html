🎯 What is Dependency Injection?

Dependency Injection (DI) is a design pattern used to implement Inversion of Control (IoC). It allows the creation of dependent objects outside of a class and provides those objects to a class in various ways.

Instead of a class instantiating its own dependencies using the new keyword, the dependencies are "injected" into the class from the outside.

💡 Why is this important for LLD?

Dependency Injection is the backbone of scalable and testable object-oriented systems. It directly enforces:

  • Dependency Inversion Principle (SOLID): High-level modules should not depend on low-level modules; both should depend on abstractions.
  • Open/Closed Principle (SOLID): Code is open for extension but closed for modification.
  • Single Responsibility Principle (SOLID): Separates the creation of an object from its business logic.
