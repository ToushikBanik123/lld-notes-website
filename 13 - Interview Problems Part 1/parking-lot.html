📌 Designing a Parking Lot System

[!info] Navigation Module: [[13 - Interview Problems Part 1/index|← Interview Problems Part 1 Overview]] Prev: [[13 - Interview Problems Part 1/logging-framework|← Designing a Logging Framework]] Next: [[13 - Interview Problems Part 1/task-management-system|Designing a Task Mgmt System →]]

🎯 Step 1: Clarify Requirements

Functional Requirements

  1. Entry: Vehicle arrives. System assigns an available slot based on Vehicle Type (Car, Bike, Truck). Generates a Ticket. Marks slot as occupied.
  2. Exit: Present Ticket. Calculate fee based on pricing rules (e.g., flat rate or hourly). Process payment. Release slot.
  3. Administration: Ability to add floors, add slots, update pricing rules.

Non-Functional Requirements

  1. Scalability: Must support multiple floors and thousands of slots.
  2. Concurrency: Handle multiple vehicles arriving at different entry gates simultaneously.

🧱 Step 2: Identify Core Entities

  1. ParkingLot: The central system.
  2. Vehicle: id, licensePlate, vehicleType (Car, Bike, Truck).
  3. ParkingSlot: id, slotType (Compact, Large), isOccupied, floorNumber.
  4. Ticket: id, vehicleId, slotId, entryTime.
  5. Receipt: id, ticketId, exitTime, totalFee.

⚙️ Step 3: Architecture & Design Patterns

We will implement a layered architecture: Controller → Service → Repository → Domain.

  1. Repository Pattern: To mock database interactions for Slots, Tickets, and Receipts.
  2. Factory Pattern: To generate different instances of PricingStrategy (e.g., HourlyPricing, FlatPricing).
  3. Strategy Pattern: To encapsulate the logic for fee calculation.

💻 Step 4: Core Implementation (C++)

cpp
#include <iostream>
#include <string>
#include <unordered_map>
#include <memory>
#include <chrono>

using namespace std;

// 1. Enums
enum class VehicleType { CAR, BIKE, TRUCK };
enum class SlotType { COMPACT, LARGE, MOTORBIKE };

// 2. Entities
class Vehicle {
public:
    string licensePlate;
    VehicleType type;
    Vehicle(string lp, VehicleType t) : licensePlate(lp), type(t) {}
};

class ParkingSlot {
public:
    int id;
    SlotType type;
    bool isOccupied;
    ParkingSlot(int i, SlotType t) : id(i), type(t), isOccupied(false) {}
};

class Ticket {
public:
    int ticketId;
    string licensePlate;
    int slotId;
    chrono::system_clock::time_point entryTime;
    
    Ticket(int tId, string lp, int sId) : ticketId(tId), licensePlate(lp), slotId(sId) {
        entryTime = chrono::system_clock::now();
    }
};

// 3. Strategy for Pricing
class PricingStrategy {
public:
    virtual double calculateFee(const Ticket& ticket) = 0;
    virtual ~PricingStrategy() = default;
};

class HourlyPricingStrategy : public PricingStrategy {
public:
    double calculateFee(const Ticket& ticket) override {
        auto now = chrono::system_clock::now();
        auto duration = chrono::duration_cast<chrono::hours>(now - ticket.entryTime).count();
        int hours = max((int)duration, 1); // Minimum 1 hour
        return hours * 10.0; // $10 per hour
    }
};

// 4. Services
class ParkingService {
private:
    unordered_map<int, shared_ptr<ParkingSlot>> slots;
    unordered_map<int, shared_ptr<Ticket>> tickets;
    int nextTicketId = 1;
    shared_ptr<PricingStrategy> pricingStrategy;

public:
    ParkingService(shared_ptr<PricingStrategy> ps) : pricingStrategy(ps) {}

    void addSlot(int id, SlotType type) {
        slots[id] = make_shared<ParkingSlot>(id, type);
    }

    shared_ptr<Ticket> parkVehicle(const Vehicle& vehicle) {
        // Find available slot (Simple linear search for demo)
        for (auto& pair : slots) {
            auto slot = pair.second;
            if (!slot->isOccupied && isSlotValidForVehicle(slot->type, vehicle.type)) {
                slot->isOccupied = true;
                auto ticket = make_shared<Ticket>(nextTicketId++, vehicle.licensePlate, slot->id);
                tickets[ticket->ticketId] = ticket;
                cout << "Vehicle " << vehicle.licensePlate << " parked at slot " << slot->id << endl;
                return ticket;
            }
        }
        cout << "No slot available for vehicle " << vehicle.licensePlate << endl;
        return nullptr;
    }

    void exitVehicle(int ticketId) {
        if (tickets.find(ticketId) == tickets.end()) {
            cout << "Invalid Ticket!" << endl;
            return;
        }

        auto ticket = tickets[ticketId];
        auto slot = slots[ticket->slotId];

        double fee = pricingStrategy->calculateFee(*ticket);
        cout << "Vehicle " << ticket->licensePlate << " exiting. Total Fee: $" << fee << endl;

        slot->isOccupied = false; // Free the slot
        tickets.erase(ticketId);  // Remove ticket
    }

private:
    bool isSlotValidForVehicle(SlotType sType, VehicleType vType) {
        if (vType == VehicleType::CAR && sType == SlotType::COMPACT) return true;
        if (vType == VehicleType::TRUCK && sType == SlotType::LARGE) return true;
        if (vType == VehicleType::BIKE && sType == SlotType::MOTORBIKE) return true;
        return false;
    }
};

// Usage
int main() {
    auto pricing = make_shared<HourlyPricingStrategy>();
    ParkingService parkingLot(pricing);

    // Admin Flow
    parkingLot.addSlot(101, SlotType::COMPACT);
    parkingLot.addSlot(102, SlotType::LARGE);

    // Entry Flow
    Vehicle myCar("ABC-123", VehicleType::CAR);
    auto ticket = parkingLot.parkVehicle(myCar);

    // Exit Flow
    if (ticket) {
        parkingLot.exitVehicle(ticket->ticketId);
    }

    return 0;
}

🚨 Edge Cases Handled

  • No Available Slots: Fails gracefully and notifies the user.
  • Pricing Strategy Swap: Because we depend on PricingStrategy (Dependency Inversion), we can easily inject a FlatPricingStrategy instead of HourlyPricingStrategy without modifying the core ParkingService.
