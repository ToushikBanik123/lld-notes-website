📌 Designing a Snake and Ladder Game

[!info] Navigation Module: [[14 - Interview Problems Part 2/index|← Interview Problems Part 2 Overview]]

🎯 Step 1: Clarify Requirements

Functional Requirements

  1. Board: A standard board of numbered cells (usually 1-100).
  2. Snakes & Ladders: A predefined set of jumps (Ladders go up, Snakes go down).
  3. Players: Multiple players playing sequentially.
  4. Movement: A dice roll (1-6) determines movement.
  5. Winning: First player to reach exactly cell 100 wins.
  6. Concurrency: The system should support multiple game sessions running concurrently for different groups.

🧱 Step 2: Identify Core Entities

  1. Board: Holds the board size, and maps of Snakes and Ladders.
  2. Player: Has a Name and a CurrentPosition.
  3. Dice: Randomizer logic.
  4. SnakeAndLadderGame: Represents a single session, orchestrating turns.
  5. GameManager: A Singleton that spins up and tracks concurrent game sessions.

⚙️ Step 3: Architecture & Design Patterns

  1. Singleton Pattern: The GameManager is a singleton to centrally manage all active game threads in the server.
  2. Factory Pattern: To generate boards with standard or randomized snake/ladder placements.
  3. Game Loop: A standard while-loop executing sequentially for each player turn within a SnakeAndLadderGame instance.

💻 Step 4: Core Implementation (C++)

cpp
#include <iostream>
#include <string>
#include <unordered_map>
#include <vector>
#include <queue>
#include <thread>
#include <mutex>
#include <cstdlib>

using namespace std;

// 1. Core Entities
struct Player {
    string name;
    int position = 0;
};

class Dice {
public:
    static int roll() {
        return (rand() % 6) + 1;
    }
};

class Board {
public:
    int size;
    unordered_map<int, int> snakes;
    unordered_map<int, int> ladders;

    Board(int s = 100) : size(s) {}

    int getFinalPosition(int currentPos) {
        if (snakes.count(currentPos)) {
            cout << "🐍 Bitten by snake at " << currentPos << " -> " << snakes[currentPos] << endl;
            return snakes[currentPos];
        }
        if (ladders.count(currentPos)) {
            cout << "🪜 Climbed ladder at " << currentPos << " -> " << ladders[currentPos] << endl;
            return ladders[currentPos];
        }
        return currentPos;
    }
};

// 2. Game Session
class SnakeAndLadderGame {
private:
    Board board;
    queue<Player> players;
    bool gameWon = false;

public:
    SnakeAndLadderGame(Board b, vector<string> playerNames) : board(b) {
        for (const auto& name : playerNames) {
            players.push({name, 0});
        }
    }

    void play() {
        while (!gameWon) {
            Player current = players.front();
            players.pop();

            int roll = Dice::roll();
            cout << current.name << " rolled a " << roll << endl;

            int newPos = current.position + roll;

            if (newPos <= board.size) {
                newPos = board.getFinalPosition(newPos);
                current.position = newPos;
                cout << current.name << " moved to " << newPos << endl;

                if (newPos == board.size) {
                    cout << "🎉 " << current.name << " WINS THE GAME! 🎉" << endl;
                    gameWon = true;
                    return;
                }
            } else {
                cout << current.name << " needs exactly " << (board.size - current.position) << " to win. Staying put." << endl;
            }

            players.push(current);
        }
    }
};

// 3. Game Manager (Singleton)
class GameManager {
private:
    static GameManager* instance;
    static mutex mtx;
    vector<thread> activeGames;

    GameManager() {}

public:
    static GameManager* getInstance() {
        lock_guard<mutex> lock(mtx);
        if (!instance) instance = new GameManager();
        return instance;
    }

    void startNewGame(vector<string> players) {
        Board b(100);
        b.snakes[99] = 10;
        b.ladders[5] = 50;

        // Start game in a new thread
        activeGames.push_back(thread([b, players]() {
            SnakeAndLadderGame game(b, players);
            game.play();
        }));
    }

    void waitForAllGames() {
        for (auto& t : activeGames) {
            if (t.joinable()) t.join();
        }
    }
};

GameManager* GameManager::instance = nullptr;
mutex GameManager::mtx;

int main() {
    srand(time(0));
    GameManager* gm = GameManager::getInstance();
    
    gm->startNewGame({"Alice", "Bob"});
    gm->startNewGame({"Charlie", "Dave"});
    
    gm->waitForAllGames();
    return 0;
}

🚨 Edge Cases Handled

  • Overshooting: Handled by validating if (newPos <= board.size). If the roll is too high, the player's position is unchanged.
  • Concurrent Sessions: GameManager spawns a new thread for each match, meaning an arbitrary number of games can progress simultaneously without blocking each other.
