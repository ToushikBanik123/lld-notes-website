📖 What is Polymorphism?

Polymorphism (from Greek: poly = many, morph = form) allows objects of different types to be treated through the same interface, while behaving differently.

[!example] Real-World Analogy 🎭 A remote control has a "play" button:

  • Press it on a TV → plays a video
  • Press it on a music player → plays music
  • Press it on a game console → starts a game

Same action ("play"), different behavior depending on the device.

1. Compile-Time Polymorphism (Method Overloading)

Same method name, different parameters. Resolved at compile time.

cpp
class Calculator {
public:
    // Same name "add" — different parameter types
    int add(int a, int b) {
        return a + b;
    }

    double add(double a, double b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }
};

int main() {
    Calculator calc;
    calc.add(5, 3);         // Calls int version → 8
    calc.add(2.5, 3.7);     // Calls double version → 6.2
    calc.add(1, 2, 3);      // Calls three-param version → 6
}

2. Runtime Polymorphism (Method Overriding)

Same method name and signature in parent and child. Resolved at runtime using virtual functions.

cpp
class Shape {
public:
    virtual void draw() {
        cout << "Drawing a generic shape" << endl;
    }
    virtual ~Shape() {}
};

class Circle : public Shape {
public:
    void draw() override {
        cout << "Drawing a circle ⭕" << endl;
    }
};

class Square : public Shape {
public:
    void draw() override {
        cout << "Drawing a square ⬜" << endl;
    }
};

class Triangle : public Shape {
public:
    void draw() override {
        cout << "Drawing a triangle 🔺" << endl;
    }
};

// THE POWER OF POLYMORPHISM:
void renderAll(vector<Shape*>& shapes) {
    for (Shape* s : shapes) {
        s->draw();  // Calls the RIGHT version at runtime!
    }
}

int main() {
    Circle c;
    Square s;
    Triangle t;

    vector<Shape*> shapes = {&c, &s, &t};
    renderAll(shapes);
    // Output:
    // Drawing a circle ⭕
    // Drawing a square ⬜
    // Drawing a triangle 🔺
}

[!tip] Why This Matters The renderAll function doesn't know or care about Circle, Square, or Triangle. It works with the base type Shape*. When you add a new shape (e.g., Hexagon), you don't change renderAll at all — it just works! This is the Open/Closed Principle in action.

[!quote] Key Takeaway Polymorphism lets you write code that works with abstractions instead of concrete types. This makes your systems extensible, maintainable, and truly object-oriented.
