📖 What is a Class?

A class is a blueprint or template for creating objects. It defines the properties (attributes) and behaviors (methods) that objects of that type will have.

[!example] Real-World Analogy Think of a class as a cookie cutter 🍪

  • The cookie cutter (class) defines the shape
  • Each cookie (object) made from it is an instance
  • All cookies have the same shape, but can have different toppings (property values)

📖 What is an Object?

An object is a specific instance of a class. It has its own state (values for properties) and can perform actions defined by its class.

🧪 Code Example

C++

cpp
#include <iostream>
#include <string>
using namespace std;

// Class Definition (Blueprint)
class Car {
private:
    string brand;
    string color;
    int speed;

public:
    // Constructor
    Car(string b, string c) : brand(b), color(c), speed(0) {}

    // Methods (Behaviors)
    void accelerate() {
        speed += 10;
        cout << brand << " accelerated to " << speed << " km/h" << endl;
    }

    void brake() {
        speed = max(0, speed - 10);
        cout << brand << " slowed to " << speed << " km/h" << endl;
    }

    int getSpeed() const { return speed; }
    string getBrand() const { return brand; }
};

int main() {
    // Creating Objects (Instances)
    Car myCar("Toyota", "Red");
    Car yourCar("Honda", "Blue");

    myCar.accelerate();   // Toyota accelerated to 10 km/h
    myCar.accelerate();   // Toyota accelerated to 20 km/h
    yourCar.accelerate(); // Honda accelerated to 10 km/h

    return 0;
}

Java

java
public class Car {
    private String brand;
    private String color;
    private int speed;

    // Constructor
    public Car(String brand, String color) {
        this.brand = brand;
        this.color = color;
        this.speed = 0;
    }

    // Methods
    public void accelerate() {
        speed += 10;
        System.out.println(brand + " accelerated to " + speed + " km/h");
    }

    public void brake() {
        speed = Math.max(0, speed - 10);
        System.out.println(brand + " slowed to " + speed + " km/h");
    }

    public static void main(String[] args) {
        Car myCar = new Car("Toyota", "Red");
        Car yourCar = new Car("Honda", "Blue");

        myCar.accelerate();   // Toyota accelerated to 10 km/h
        yourCar.accelerate(); // Honda accelerated to 10 km/h
    }
}

Constructors

  • Default Constructor: No parameters, initializes with defaults
  • Parameterized Constructor: Takes arguments to set initial state
  • Copy Constructor: Creates a copy of an existing object (C++ specific)

[!quote] Key Takeaway A class defines what something is and what it can do. An object is a living, breathing instance of that class with its own unique state.
